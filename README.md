# Content Copilot

Контент-напарник для Claude Code. Помогает писать посты, которые звучат как живой человек, а не как нейросеть.

## Что это

Агент с личностью опытного интервьюера-редактора:
- Вытаскивает истории из людей, которые "не умеют рассказывать"
- Проверяет тексты на нейроштампы
- Пишет посты с конкретикой
- Анализирует и сохраняет авторский стиль

## Установка

### Один шаг — копируй и вставляй в терминал:

```bash
mkdir -p ~/.claude/commands && curl -sL https://raw.githubusercontent.com/tari-lucy/content-copilot/main/content-copilot.md -o ~/.claude/commands/content-copilot.md && echo "✅ Content Copilot установлен!"
```

### Проверить, что установилось:

```bash
cat ~/.claude/commands/content-copilot.md | head -5
```

### Готово!

Теперь в Claude Code можешь писать:
- "Проверь текст на штампы"
- "Напиши пост про мою фичу"
- "Улучши этот текст"

---

## Что умеет

**🔍 Проверка текста**
Находит нейроштампы, воду, канцеляризмы. Объясняет, почему плохо и как исправить.

**✍️ Написание постов**
Задаёт правильные вопросы, вытаскивает факты, пишет по структуре: зацепка → суть → доказательство → вывод.

**🔧 Улучшение текста**
Убирает штампы, добавляет конкретику. Показывает "было → стало".

**🎨 Анализ стиля**
Анализирует твои тексты и создаёт профиль стиля для будущих генераций.

---

## Примеры

**Написать пост:**
```
Напиши пост про новую фичу — автосохранение.
Для разработчиков, чтобы попробовали.
```
→ Агент спросит про цифры, боли, результаты — и напишет живой текст

**Проверить текст:**
```
Проверь этот текст:
Давайте честно: наш инновационный продукт позволяет
значительно ускорить процесс создания качественного контента.
```
→ Найдёт 5 штампов, объяснит почему плохо, предложит переписать

**Улучшить текст:**
```
Улучши: Мы — команда профессионалов с индивидуальным подходом.
```
→ Спросит факты и перепишет с конкретикой

## Что внутри агента

- 🔴 Полный справочник нейроштампов (10 категорий с примерами)
- 📝 Правила "Пиши, сокращай" (стоп-слова, структура, синтаксис)
- 🎤 Вопросы для вытягивания фактов (9 типов контента)
- 🔄 Примеры трансформации (было → стало)
- ✅ Чек-лист редактуры

**763 строки** прокачанных инструкций — агент знает, как писать без штампов.
